# Ditte Helene Andersen — Design Portfolio

A responsive static portfolio built with HTML and CSS, following the supplied desktop, tablet, and mobile Figma frames.

## Run locally

From this directory, start Python's built-in static server:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Design assets

The page expects these Figma image exports in `assets/`:

- `portrait.jpg`
- `studio-assistant.jpg`
- `shift-leader.jpg`
- `artist-crew-member.jpg`
- `hostess.jpg`

The design file's image fills are not available as workspace files through the current Figma connector, so add those exports before publishing. The layout and grayscale treatment are already wired to these filenames.
